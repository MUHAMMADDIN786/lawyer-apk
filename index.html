How to install (under a minute)

  1. Tap the green button above — the file downloads to your phone
  2. Open the downloaded file
  3. Android will show a security prompt — tap Settings, turn on Allow from this source, then go back and tap Install

That prompt is normal. It only shows up because this app is installed directly instead of through the Play Store — it doesn't mean anything is wrong.

About this app

Keep every case, hearing date, and client on your phone — no internet needed. Add an optional cloud backup when you want one, and invite an associate to help manage your caseload with their own permissions.

Built by an independent developer, not a big firm — just a tool made to fit how Pakistani lawyers actually keep their diary.
