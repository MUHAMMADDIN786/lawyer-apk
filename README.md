# Lawyer's Diary

Welcome — this is the official release page for **Lawyer's Diary**, a free,
offline-first case and hearing diary built for Pakistani lawyers.

Keep every case, hearing date, and client on your phone — no internet
needed. Add an optional cloud backup when you want one, and invite an
associate to help manage your caseload with their own permissions. Built
by an independent developer, not a big firm — just a tool made to fit how
Pakistani lawyers actually keep their diary.

## Download

**[⬇ Download the latest stable release](https://github.com/MUHAMMADDIN786/lawyer-apk/releases/latest)**

This is always the newest, stable build — every release replaces the one
before it at the same link, so there's never an old version to hunt for.

Direct APK link (same target, for linking from elsewhere):
```
https://github.com/MUHAMMADDIN786/lawyer-apk/releases/latest/download/lawyers-diary-latest.apk
```

Since this build is installed directly rather than through the Play
Store, Android will ask you to confirm the install once — tap **Settings**
on that prompt, allow installs from your browser, then go back and tap
**Install**. This is normal and only appears the first time.

## About this repo

Public release host for Lawyer's Diary Android builds.

This repo intentionally does not track the `.apk` binary in git history —
each build is attached as a GitHub Release asset instead (Releases →
Draft a new release → upload the `.apk` renamed to
`lawyers-diary-latest.apk` → Publish). Publishing a new release with that
same asset filename is the entire update workflow: the stable download
link never changes.

Source code for the app lives in a separate, private repository.
